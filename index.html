What's in it
Features
🧱
Raycasting
Wolfenstein-style 3D rendering — no 3D engine, just maths and rays cast per column of pixels.
🤖
Enemy AI
Enemies that roam the map, detect the player, and chase them down. 10 kills to clear the level.
🗺️
Minimap
Real-time minimap rendered in the corner showing walls, player position and enemy locations.
❤️
HP System
Health bar tracks damage taken. Hit 0% and it's game over — stats screen shows kills and time.
🎯
Shooting
Hitscan shooting with visual feedback. Line up the crosshair and pew pew.
⚡
No Dependencies
Built with C++ and SDL2 only. Compiles on Mac, Linux and Windows with a single make command.
Run It
Build & Play
# Clone the repo
git clone https://github.com/RiyanMujtaba/cpp-raycaster
cd cpp-raycaster

# Install SDL2 (Mac)
brew install sdl2 sdl2_image sdl2_ttf

# Build and run
make && ./raycaster
# Controls
W A S D     Move
← →        Look
SPACE       Shoot
ESC         Quit
